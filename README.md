## Projets

### 🐾 [RefuConnect](https://github.com/abdobeny/Refuconnect)
Plateforme de gestion pour refuge animalier : adoption, toilettage, couplage, dons et bénévolat.
- Site public en React, API Laravel 11, panneau d'administration Filament avec statistiques
- Authentification par tokens Sanctum, espace utilisateur pour suivre adoptions et dons
- Image Docker de production, CI GitHub Actions (tests backend + build frontend)

`Laravel` `Filament` `React` `MySQL` `Docker`

### 🌍 [TripFlow Morocco](https://github.com/abdobeny/Tripflow)
Plateforme de réservation de voyages au Maroc : circuits, safaris dans le désert, treks et villes.
- Recherche avec suggestions en direct, parcours de réservation, suivi des réservations
- Contact direct avec un agent via WhatsApp, panneau admin Filament
- Interface responsive avec Tailwind CSS et Framer Motion

`Laravel` `Filament` `React` `Tailwind` `MySQL`

### 📝 [php-blog-mvc](https://github.com/abdobeny/php-blog-mvc)
Blog en PHP avec un noyau MVC écrit à la main, sans framework ni Composer. PDO/MySQL, protection CSRF et espace admin par rôles.

`PHP` `MySQL` `MVC`

### 💼 [Portfolio](https://portfolio.benyousseabdelilah.workers.dev)
Mon portfolio, en React + Vite, déployé sur Cloudflare.
